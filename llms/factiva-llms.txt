# Factiva

> Factiva is Dow Jones' business information and research service: a licensed global news
> archive of more than 33,000 sources, wrapped in an API suite for search, retrieval, bulk
> extraction, real-time streaming and taxonomy lookup. Access is contract-based — there is no
> self-service signup and no public pricing. Credentials come from a Request Trial form and a
> sales conversation. This file was generated by API Evangelist from the provider's own
> published documentation and specifications; Factiva does not serve an llms.txt of its own.

## Access model

- Base host: https://api.dowjones.com
- Authentication: `user-key` header (API key) OR `Authorization: Bearer` token
- Token endpoint: https://accounts.dowjones.com/oauth2/v1/token (OAuth 2.0 password grant, connection=service-account)
- OIDC discovery: https://accounts.dowjones.com/.well-known/openid-configuration
- Versioning: `X-API-VERSION` request header; GenAI endpoints use `Accept: application/vnd.dowjones.genai-content.v_N.N`
- Errors: JSON:API-style `errors[]` envelope with numeric Dow Jones codes — not RFC 9457
- Rate limits: not published
- Idempotency: not supported

## APIs

- [Factiva Snapshots API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics-endpoints-snapshots-snapshots_3_0): One-time extraction of historical Factiva content matching a query. Version 3.0.
- [Factiva Streams API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics-endpoints-streams-streams_3_0): Real-time event delivery over Google Cloud Pub/Sub. Version 3.1.
- [Factiva Extractions API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics-endpoints-bulk_source_events): Large-scale extraction and bulk source events.
- [Factiva Analytics API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics): Explain jobs, time series and volume estimation over the archive.
- [Factiva Taxonomy / DJID API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics-endpoints-taxonomy_list_download): ~350,000 Dow Jones Intelligent Identifier codes for companies, industries, regions and news subjects.
- [Factiva Retrieval API](https://developer.dowjones.com/documents/factiva_integration-factiva_retrieval_api-endpoints-retrieval): Licensed article retrieval for RAG stacks, with mandatory per-transaction usage reporting. Version 1.0.
- [Factiva Content API](https://developer.dowjones.com/documents/factiva_integration-factiva_analytics-article_viewing_options-factiva_article_fetch): Search and article fetch, including binary renditions and publisher redirects.
- [DJ Factiva Newsletters API](https://developer.dowjones.com/documents/factiva_integration-factiva_workflow_toolkit-endpoints-newsletters-newsletters): Curated newsletters, editions and deliveries.
- [Factiva Company News Radar API](https://developer.dowjones.com/documents/site-docs-factiva_apis-factiva_workflow_apis_rest-factiva_news_search-news_radar_api-news_radar): Company screening list and news radar over the realtime index.
- [Factiva Sentiment Signals API](https://developer.dowjones.com/documents/factiva_integration-factiva_sentiment_signals-endpoints-sentiment_signals): Sentiment datasets. Version 1.0.

## Specs

Three machine-readable specifications are published, served from the Dow Jones developer portal.
The Snapshots, Streams, Extractions, Analytics, Taxonomy and Retrieval endpoints are documented
in prose only — no specification exists for them.

- [Factiva Content API — Swagger 2.0](https://developer.dowjones.com/wp-json/swagger/v1/api/2666): 15 paths, 16 operations. Local copy: openapi/factiva-content-api-swagger.json
- [DJ Factiva Newsletters API — OpenAPI 3.0.2](https://developer.dowjones.com/wp-json/swagger/v1/api/2668): 4 paths, 4 operations. Local copy: openapi/factiva-newsletters-api-openapi.json
- [Factiva Company News Radar API — OpenAPI 3.0.1](https://developer.dowjones.com/wp-json/swagger/v1/api/2672): 2 paths, 2 operations. Local copy: openapi/factiva-company-news-radar-api-openapi.json
